# VedaTax Website

React (Vite) frontend + ASP.NET Core 8 Web API + PostgreSQL.

The Services menu has exactly three services — **US Taxation**, **Canada Taxation**, **India Taxation** — each with its own submenu, modelled on the navigation of the reference site (bluewingstax.com).

```
backend/   VedaTax.sln, VedaTax.Api (.NET 8 Web API, EF Core + Npgsql, JWT auth)
frontend/  React 18 + React Router 6 (Vite)
```

## What's included

| Area | Behaviour |
|---|---|
| Header → **Services ▾** | Opens on hover or click. Left column: US / Canada / India Taxation. Hovering or focusing one shows its sub-services on the right, plus "All … services" and a consultation button. Esc / outside click closes it. |
| Mobile menu | Hamburger → Services → country → sub-services (nested accordions). |
| Country selector | US / Canada / India, like the reference's `?country=` selector. It changes the home hero copy, the service grid and pricing, and is kept in the URL and localStorage. |
| Home → Services section | Three cards (one per country). **View services** opens a pop-up listing that country's sub-services. |
| Free consultation pop-up | Opened from Get Started, menu, cards, service pages and the assistant. You pick US / IN / CA, then a service from that country, and it POSTs to `/api/enquiries`. |
| Assistant pop-up | Bottom-right "A question before you file?" card, shown once per browser session. |
| Service pages | `/services/:country/:slug`: overview, what to prepare, how it works, FAQs, official link, "Your next step" sidebar, related services. |
| Pricing | Starting prices per country (from the DB). |
| Login / Register | JWT auth. After signing in, clients land in the client portal (`/portal`). |

## Client portal (`/portal`)

Modelled on the reference client area. It has its own layout: a dark sidebar, a tax-year selector, and a user menu (Profile details, Change password, Sign out).

| Screen | What it does |
|---|---|
| Tax-year selector | Each **filing** is one country + tax year (US `2025`, Canada `2025`, India `FY 2025-26`). Use "Start another filing…" to add one. |
| Dashboard | Deadline alert (IRS Apr 15 / CRA Apr 30 / ITD Jul 31), file-status bar (Registered → Documents Uploaded → Preparation Pending → Review Completed → Invoice Paid → Completed), next step, referral stats, consultation requests. |
| Tax Organizer | 3 steps: download a country-specific `.docx` organizer (generated by the API), fill it, upload it. |
| Documents | Tabs: My uploads / From VedaTax / Downloads. The upload pop-up offers country-specific document types (W-2/1099…, T4/T5…, Form 16/AIS…). Clients can download files and delete their own uploads. |
| Invoice | Invoice number/date, line items, referral bonus deduction, final amount, Print / Save PDF. Shows "not generated yet" until staff create it. |
| Refer & Earn | Add one or more friends (name, email, phone). Bonus: $25 / C$25 / ₹1,000 when the friend pays. |
| My Referrals | Searchable list; status Invited → Registered (friend signed up) → Paid (friend paid, bonus earned). |
| Profile details | Name, phone, alternative phone (email is read-only). |

Your **personal consultant** appears in the sidebar once staff assign one.

Uploaded files are stored on disk under `backend/VedaTax.Api/App_Data/uploads` (`Storage:UploadsPath`, max 15 MB, PDF/images/Office/CSV/TXT/ZIP). The company details printed on invoices come from the `Company` section of `appsettings.json` (placeholders for now).

## Staff area (`/admin`)

Users with role `Admin` land here after signing in; clients who open `/admin` are sent to `/portal`, and staff who open `/portal` are sent to `/admin`. The header shows **Staff area** instead of **My account** for staff.

| Screen | What it does |
|---|---|
| Client filings | Counters per file status (click to filter), search by client / email / consultant, country and status filters. Click a client to open the filing. |
| Filing detail | **Status & consultant:** set the file status and the consultant shown in the client's sidebar. **Client:** contact details and the referral credit usable on this invoice. **Documents:** download any file; share a file under "From VedaTax" (for review) or "Downloads" (final copies); remove files staff shared. **Invoice:** add or edit line items, apply the client's referral credit automatically or enter a custom amount, live totals, create or update, then **Mark as paid** (locks the invoice and moves the filing to Invoice Paid). |
| Consultation requests | Requests from the website's free-consultation pop-up, with search and status (New / Contacted / Converted / Closed). |

### Staff endpoints (role `Admin`)

The staff screens use these endpoints (also available in Swagger):

| Method | Route | Purpose |
|---|---|---|
| GET | `/api/admin/filings` | All client filings |
| GET | `/api/admin/filings/{id}` | Filing detail: client, documents, invoice, usable referral credit |
| GET / DELETE | `/api/admin/documents/{id}/download`, `/api/admin/documents/{id}` | Download any file / remove a staff-shared file |
| PUT | `/api/enquiries/{id}/status` | Set a consultation request's status |
| PUT | `/api/admin/filings/{id}` | Set `status` and/or the consultant (`consultantName`, `consultantEmail`, `consultantPhone`) |
| POST | `/api/admin/filings/{id}/documents` | Share a file (multipart: `category` = `expert` or `download`, `documentType`, `file`, `comments`) |
| PUT | `/api/admin/filings/{id}/invoice` | Create/replace the invoice (`items[]`; referral bonus applied automatically unless `referralBonus` is given) |
| POST | `/api/admin/filings/{id}/invoice/paid` | Mark the invoice paid (moves the filing to Invoice Paid) |

In Development a staff account is created from `SeedAdmin` in `appsettings.Development.json`. Remove that section or change it for any shared environment.

### Sub-services (seeded)

- **US Taxation:** Individual Tax Filing, ITIN, Business Tax & Accounting, FBAR & FATCA, Tax Planning, LLC & Company Formation
- **Canada Taxation:** T1 Personal, T2 Corporate, GST/HST, Payroll & T4/T5 Slips, Newcomers & Non-Residents, US–Canada Cross-Border
- **India Taxation:** ITR Filing, NRI & DTAA, GST, TDS, Company Registration, Tax Advisory

The content lives in [`backend/VedaTax.Api/Data/DbSeeder.cs`](backend/VedaTax.Api/Data/DbSeeder.cs) and is written to the database on first run. After that, edit it in the DB (`tax_services`, `service_faqs`). The seeder only runs when `countries` is empty.

## Prerequisites

- .NET SDK 8 or later (the project targets `net8.0`)
- Node.js 18+ (LTS recommended)
- PostgreSQL 14+

## Run the backend

1. Create the database (or let EF create it):

   ```sql
   CREATE DATABASE vedatax;
   ```

2. Set the connection string in `backend/VedaTax.Api/appsettings.json` (default: `Host=localhost;Port=5432;Database=vedatax;Username=postgres;Password=postgres`), or use user-secrets:

   ```bash
   cd backend/VedaTax.Api
   dotnet user-secrets init
   dotnet user-secrets set "ConnectionStrings:Default" "Host=localhost;Database=vedatax;Username=postgres;Password=YOUR_PASSWORD"
   ```

3. Run it. On startup it applies migrations and seeds the services.

   ```bash
   cd backend
   dotnet run --project VedaTax.Api
   ```

   API: http://localhost:5080. Swagger: http://localhost:5080/swagger

For production, set `Jwt__Key` (32+ characters) as an environment variable. The development key in `appsettings.Development.json` is for local use only.

### API endpoints

| Method | Route | Notes |
|---|---|---|
| GET | `/api/services/menu` | Services mega-menu data (3 countries + sub-services) |
| GET | `/api/services/{country}` | Country hero copy + service cards (`us`, `ca`, `in`) |
| GET | `/api/services/{country}/{slug}` | Service detail page |
| POST | `/api/enquiries` | Free consultation request (anonymous) |
| GET | `/api/enquiries/mine` | Signed-in user's enquiries |
| GET | `/api/enquiries` | All enquiries (role `Admin`) |
| POST | `/api/auth/register`, `/api/auth/login` | Returns a JWT |
| GET | `/api/auth/me` | Current user |
| POST | `/api/auth/change-password` | Change password (signed in) |
| * | `/api/portal/...` | Client portal: filings, overview, organizer, documents, invoice, referrals, profile |

To make a staff user: `UPDATE users SET "Role" = 'Admin' WHERE "Email" = '...';`

### Migrations

```bash
cd backend
dotnet tool restore
dotnet ef migrations add <Name> --project VedaTax.Api
```

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. Vite proxies `/api` to `http://localhost:5080`.

For a production build, set `VITE_API_BASE_URL` (see `.env.example`), then run `npm run build`.
